# Bundled original assets — V4.2

These files were decoded directly from the family-supplied `roora-photos.json` WebP pack. They are not placeholders and no remote import is required. `npm run assets` verifies the six expected files. `npm run build` runs this check as a mandatory step before Next.js builds. All six files must be committed to the repository; confirm with `git ls-files public/media/*.webp`.

The four portraits and two outfit boards are publicly addressable when served from Next.js `public/`. Keep sensitive guest/location information outside this directory. The photos are illustrative memories, not verified photographs of the original meeting or engagement dates.
